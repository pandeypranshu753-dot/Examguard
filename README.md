# ExamGuard

ExamGuard is a web-based online examination and proctoring system built with Python, Flask, SQLite, HTML, CSS and JavaScript.

## Features

- Student login and logout
- Secure password hashing
- Online MCQ examination
- 30-minute exam timer
- Automatic submission
- Automatic score calculation
- Answer storage
- Exam result history
- Webcam monitoring
- Face detection
- Multiple-face detection
- No-face detection
- Tab-switch detection
- Proctoring event logging
- Suspicious activity detection
- Proctoring logs dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- MediaPipe Face Detection
- Git & GitHub
